Política de privacidade

Última atualização: 5 de novembro de 2026.

A LocaMaq é uma empresa fictícia e este site é um case de portfólio. O formulário de orçamento funciona de verdade, como demonstração de uma automação, e por isso esta página explica com clareza o que acontece com os dados enviados nele. Se você só quer testar, use dados fictícios.

Quem é o responsável

O autor do case, identificado no GitHub como kaekoff-ux. Para qualquer assunto desta página, escreva para kae.koff@gmail.com.

Quais dados o formulário coleta

  • nome;
  • e-mail ou telefone de contato;
  • cidade (opcional);
  • equipamento escolhido e, se houver, o modelo;
  • prazo desejado e o resumo da simulação (dias e horas de uso por dia);
  • observações escritas por você (opcional);
  • data e hora do envio.

O formulário não pede CPF, endereço completo, dados de pagamento nem documentos. Evite escrevê-los no campo de observações.

Para que os dados são usados

Apenas para registrar o pedido de orçamento e demonstrar o fluxo de atendimento do case. Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros além dos serviços descritos abaixo.

Onde os dados ficam e quem os processa

  • Automação (n8n): o formulário envia os dados a um fluxo de automação que roda em um servidor na Amazon Web Services, nos Estados Unidos.
  • Planilha (Google Sheets): o fluxo grava cada pedido em uma planilha privada do autor, no Google Drive.
  • Avisos internos (Slack): o pedido pode ser repassado a um canal interno de Slack, só para avisar a equipe.
  • Fontes de letra: a página carrega fontes do Google Fonts, o que faz o seu navegador contatar o Google e revelar o seu endereço IP.

Uso de dados do Google

A automação acessa o Google Sheets e o Google Drive somente com a conta do autor, para gravar os pedidos na planilha dele. Os visitantes do site não entram com a conta Google e a automação não lê dados pessoais de visitantes no Google.

Por quanto tempo os dados ficam

Enquanto o case estiver no ar, ou até você pedir a exclusão, o que ocorrer primeiro.

Seus direitos

Conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você pode pedir a confirmação de que tratamos seus dados, o acesso a eles, a correção, a exclusão ou a oposição ao uso. Envie o pedido para kae.koff@gmail.com, informando o nome e o contato que usou no formulário.

Segurança

Os dados viajam por conexão segura (HTTPS) e o acesso à planilha e à automação é restrito ao autor, com senha. Nenhum sistema é totalmente imune a falhas, por isso não envie informações que você não queira compartilhar.

Mudanças nesta política

Se algo mudar, a data de atualização no topo desta página muda junto.
